# Global Data Professionals Analytics Dashboard

## Overview
Developed an interactive Power BI dashboard to analyze global survey data from data professionals across different roles, countries, and industries.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Excel

## Analysis Performed
- Salary trend analysis by job role
- Work-life balance and satisfaction analysis
- Programming language preference analysis
- Country-wise comparison of data professionals
- Career entry difficulty analysis

## Dashboard Features
- Interactive filters and slicers
- KPI and gauge visualizations
- Dynamic charts and reports
- Data cleaning and transformation using Power Query
