\# Global Data Professionals Analytics Dashboard



\## Overview

Interactive Power BI dashboard analyzing survey data from global data professionals.



\## Tools Used

\- Power BI

\- DAX

\- Power Query

\- Excel



\## Key Insights

\- Salary trends across data roles

\- Work-life balance analysis

\- Programming language preferences

\- Difficulty entering data careers

\- Country-wise comparisons



\## Features

\- Interactive filters

\- KPI metrics

\- Data visualizations

\- Survey analysis dashboard
